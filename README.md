# Zomato Customer Support Chatbot

A customer support chatbot for a food delivery app, built with HTML, CSS and JavaScript.

## Features
- Track order, refund status, cancellation, missing items and payment problems
- Quick-reply buttons and order status cards
- Works in English, Hindi and Bengali (including typed Hinglish)
